⚠️ 你现在是直接双击打开的（file:// 方式），浏览器不允许这样烧录

出于安全限制，浏览器禁止网页在 file:// 下读取本地固件文件（manifest.json、firmware.bin），也禁止加载本地模块脚本，所以按钮不会有反应。

解决办法（任选一个，一分钟搞定）：

  1. 双击同目录的「启动烧录服务.cmd」 —— 它会自己起一个本地小服务器并自动打开浏览器（推荐）。
  2. 在 PowerShell 里执行：
    cd "这个文件夹的路径"; node server.js
  3. 或者用 Python：
    cd "这个文件夹的路径"; python -m http.server 8930
    然后浏览器访问 http://localhost:8930/

服务启动后，浏览器地址栏要显示 http://localhost:8930/，而不是 file:///...。

刷机流程
  1. 用 数据线连接开发板 → 点 连接并安装 → 在弹窗里选对应的串口（CH340 / CP210x / USB JTAG 之类）。
  2. 首次刷机建议勾选「擦除设备」，等待写入完成（约 30 秒）。
  3. 刷完按板上的 RST 键复位。
  4. 手机蓝牙搜索 视频遥控器 配对（不需要 PIN 码）→ 打开抖音/快手 → 板载 BOOT 键：短按＝下一个视频、双击＝上一个、长按＝暂停。
  5. 手机连 WiFi 热点 视频遥控器（密码 12345678），会自动弹出配置页，可以调滑动距离、灵敏度、落点位置等参数。
💡 以后升级固件不用数据线了
手机或电脑连上设备的热点后，访问 192.168.4.1/update，把新的 firmware.bin 拖进去上传即可（网页 OTA）。
这个烧录页只在「第一次刷机」或「OTA 也进不去」时才需要用。
找不到串口 / 烧录失败？
  1. 确认 USB 线支持数据传输，不是纯充电线。
  2. 拔掉 USB → 按住板上的 BOOT 键不放 → 重新插上 USB 再松开 → 再点一次安装。
  3. 关掉其他占用串口的软件（串口助手、Arduino IDE 串口监视器、这个页面之前的旧标签页）。
  4. 换电脑端 Chrome 或 Edge，不要用手机浏览器刷机。
  5. Windows 上如果连串口都看不到，先装对应 USB 驱动（CH340 / CP210x）。
