## 这是什么

一块 10 块钱的 ESP32-C3 Super Mini，插上手机蓝牙后，手机会把它当成**蓝牙鼠标**。  
按板载那颗 BOOT 键，设备会自动在屏幕上做一次垂直滑动 —— 抖音 / 快手就翻页了。

|        手势        | 动作        | 手机上发生了什么 |
| :--------------: | :-------- | :------- |
|     **短按一下**     | 下一个视频 ⬇   | 往上滑      |
|     **快速点两下**    | 上一个视频 ⬆   | 往下滑      |
| **按住不放**（≥0.6 秒） | 暂停 / 继续 ⏸ | 点一下屏幕    |

**不用接任何线**，只用板子上原本就有的那颗 BOOT 键（GPIO9）。  
想用独立按键也可以，外接两个轻触开关到 GPIO2 / GPIO3 即可，一按一个动作、零延迟。

## 特点

- 🖱 **纯蓝牙鼠标方案**，不需要装任何 App、不需要无障碍权限、不需要联网
- 🎮 **单键手势**：短按 / 双击 / 长按分别对应 下一个 / 上一个 / 暂停
- ⚙️ **热点配置页**：设备自己开 WiFi 热点，手机连上就能进网页调参数
- 🎯 **一键落点校准**：用抖音自己的反馈当标尺，十秒标定完，永久生效
- 🎡 **三种翻页方式**：鼠标滑动 / 鼠标滚轮 / 键盘方向键，可在网页随时切换
- ⚡ **网页烧录**：电脑打开网页点一下就能刷机，不用装开发工具
- 📦 **网页 OTA**：以后升级固件不用再插数据线，手机连热点上传 .bin 就行
- 🇨🇳 **全中文界面**：烧录页、配置页、日志全是中文

## 硬件清单

| 东西                  | 说明                   |  必需 |
| :------------------ | :------------------- | :-: |
| ESP32-C3 Super Mini | 任意 4MB Flash 版本即可    |  ✅  |
| USB 数据线             | 烧录用，**必须是数据线不能是充电线** |  ✅  |
| Android / iOS 手机    | 都能用                  |  ✅  |
| 轻触按键 × 2            | 可选，外接到 GPIO2 / GPIO3 |  ⭕  |
| 杜邦线 / 电池模块          | 可选，做成便携遥控器           |  ⭕  |

板载只有两个键：`BOOT`（GPIO9）和 `RST`。  
`RST` 是硬复位键，按下直接重启芯片，**不可能当功能键**，所以板载能自定义的只有 BOOT 一颗。

## 烧录方式（三选一）

### 方式一：网页一键烧录（推荐，零安装）

**在线地址：<https://991123.xyz/esp/ble>**

1. 用数据线把开发板接到电脑
2. 浏览器打开上面的地址（电脑端 **Chrome** 或 **Edge**）
3. 点蓝色的 **「⚡ 连接并安装」** → 在弹窗里选对应的串口
4. 等进度条走完（约 30 秒），按板上的 `RST` 复位

> 烧录组件已经打包进仓库，**断网也能刷**，不依赖任何 CDN。
>
> 备用地址（GitHub Pages 自动部署）：<https://xxlowr9.github.io/esp32-c3-ble/webflash/>
>
> 两个地址任选其一，功能完全一样。

### 方式二：下载到本地烧录

1. 下载本仓库的 `webflash` 文件夹
2. 双击 **`启动烧录服务.cmd`**（优先用 Node.js，没有就自动改用 Python）
3. 浏览器会自动打开 `http://localhost:8930/`
4. 点 **「⚡ 连接并安装」**，和方式一完全一样

> 用完在黑色窗口按 `Ctrl+C` 关闭服务。  
> 之所以需要这一步：浏览器不允许网页在 `file://` 协议下读取本地固件文件，必须走 `http://`。

### 方式三：第三方在线工具 / esptool

如果不想用网页，直接用 [ckxingchen.cn/tools](https://ckxingchen.cn/tools) 这类在线烧录工具：

**A. 整包（最简单）** —— 上传 `webflash/merged_整包0x0.bin`，写入地址 `0x0`

**B. 分文件**

| 文件               | 写入地址      |
| :--------------- | :-------- |
| `bootloader.bin` | `0x0`     |
| `partitions.bin` | `0x8000`  |
| `boot_app0.bin`  | `0xE000`  |
| `firmware.bin`   | `0x10000` |

> 分区表是 **No FS 4MB（2MB APP × 2）**，必须含 OTA 分区，OTA 升级才可用。

### 把烧录页部署到自己的服务器

`webflash/` 就是一个**纯静态站点**，扔到任何能放静态文件的地方都能用（Nginx / Apache / 宝塔 / GitHub Pages / 对象存储）。

必须满足两点：

1. **走 `http://` 或 `https://`**，不能是 `file://`（浏览器安全策略）；
2. **`_webtools/` 目录要和 `index.html` 放在一起**，相对路径才对。

以宝塔面板为例：

1. 文件 → 进入站点根目录 → 新建目录 `esp`，再新建 `ble`
2. 把 `webflash/` 里的**全部内容**（`index.html`、`manifest.json`、几个 `.bin`、`_webtools/`）上传到 `ble` 目录里
3. 访问 `https://你的域名/esp/ble/` 就能打开烧录页

用 GitHub Pages 的话更简单：仓库 **Settings → Pages → Source 选 `main` 分支 / `root`**，  
保存后地址就是 `https://<用户名>.github.io/esp32-c3-ble/webflash/`。

## 使用说明

1. 手机「设置 → 蓝牙」搜索 **视频遥控器** 配对（**不需要 PIN 码**，点一下就配上了）
2. 屏幕上出现一个小圆点光标 = 鼠标已被识别，这一步最关键
3. 打开抖音 / 快手，进入全屏播放
4. **短按** BOOT 键 → 下一条；**双击** → 上一条；**长按** → 暂停
5. 想调参数：手机连 WiFi 热点 **视频遥控器**（密码 `12345678`），会自动弹出配置页，或手动访问 `192.168.4.1`

### 外接两个独立按键（可选）

想要一个键一个动作、没有双击等待延迟，就外接两个轻触开关：

```
外接按键 1：GPIO3 ──┤ ├── GND   → 下一个视频（短按即发，零延迟）
外接按键 2：GPIO2 ──┤ ├── GND   → 上一个视频
```

所有引脚都开了内部上拉，**不需要外接电阻**。接线前先断电，接好再上电。  
在配置页关掉「单键模式」后，板载 BOOT 键会变成「按一下 = 下一个」的直接模式。

## 网页配置

设备开的热点里有个配置页（`192.168.4.1`），所有参数**改完立即生效，不用点保存**。

| 参数           | 作用                    | 默认  |
| :----------- | :-------------------- | :-- |
| ⚡ 滑动灵敏度 1~10 | 一次调两个底层参数：滑得更长 + 更快   | 5   |
| 滑动距离         | 一次滑动走多远（单位是鼠标位移，不是像素） | 120 |
| 步间隔 ms       | 每步之间的停顿，越小滑得越快        | 12  |
| 滑动 X / 点击 X  | 横向落点，**都建议贴屏幕最左**     | 30  |
| 起手 Y         | 纵向落点（屏幕高度的比例位置）       | 200 |
| 屏幕高度         | 整屏等于多少个位移单位（校准得来）     | 500 |
| 长按判定 ms      | 按住多久算长按               | 600 |
| 双击窗口 ms      | 两次点击间隔多久算双击           | 320 |
| 🎡 滚轮模式      | 改用鼠标滚轮翻页（完全不涉及坐标）     | 关   |
| 方向反转         | 方向反了就勾上               | 关   |

### 🎯 落点校准（第一次用建议做一次）

蓝牙鼠标只有「相对移动」，设备不知道你手机的鼠标灵敏度（各家差别很大，1 个位移单位可能等于 1~3 像素）。  
所以落点要**标定一次**，方法很直白 —— 拿抖音自己的反馈当标尺：

**① 点校准**  
在抖音里播放视频，点配置页的「① 点校准」。设备会每隔 1.5 秒往屏幕下方点一次，  
**看到视频「暂停」了**，立刻点网页上的「✓ 就用这档」→ 由此推算出你的屏高、起手点和滑动距离。

**② 翻页校准**  
点「② 翻页校准」，设备逐档加大滑动幅度，**看到翻页了**就点「✓ 就用这档」→ 滑动距离定死。

十秒钟的事，校准完永久生效。

> 校准期间如果点到了顶部 tab 区域、切换了「关注/推荐」，回到推荐页继续就好。

## 为什么是「鼠标滑动」而不是「键盘方向键」？

这是本项目踩过最大的坑，值得写清楚：

**手机版抖音 / 快手完全不响应键盘按键。** 方向键、PageDown、音量键都实测过 ——  
手机系统收到了（日志里全是「已发送」，音量键也确实响了），但 **APP 根本不翻页**，因为它们没有绑定键盘事件。

有效办法只有一个：**模拟鼠标按住屏幕上下拖动**。安卓会把它当成手指滑动，抖音才认。

市面上同类翻页器走的也是这条路。

（顺便一提：纯 BLE 键盘方案在这个 ESP32 核心上还做不了 —— 核心的 BLE 库用 UUID 当键存特征表，  
同一个 `0x2A4D` 只能存在一个，HID 键盘必须用独立的 input report，开第二个会变野指针、`notify()` 直接 assert 崩溃。）

## 常见问题

**Q：刷机时找不到串口？**  
A：① 换一根**确认能传数据**的 USB 线；② 拔掉 USB → 按住 BOOT 键不放 → 重新插上 USB 再松开 → 再点一次安装；③ 关掉其他占用串口的软件（串口助手、Arduino IDE 串口监视器）；④ Windows 上连串口都看不到就装 CH340 / CP210x 驱动；⑤ 用电脑端 Chrome / Edge，不要用手机浏览器刷机。

**Q：手机连上了蓝牙但抖音没反应？**  
A：看配置页的日志。出现「手机没订阅通知」说明手机没把这个设备认成鼠标，删掉手机里的配对记录重新配一次。  
出现「已发送手势」但手机没反应，多半是落点不对 → 做一次上面的落点校准。

**Q：滑动的时候弹出了通知栏 / 退回了桌面？**  
A：这是滑动落点贴到了屏幕边缘，触发了系统手势。固件已经有「安全带」硬保护（顶部 10%、底部 15% 划为禁区），  
但参数没校准时仍可能偏 —— 做一次落点校准即可；也可以把「起手 Y」往中间调。

**Q：长按暂停点到了评论区 / 点了别的？**  
A：抖音右侧一列是头像、点赞、评论、收藏、分享。点错了说明「点击 X」太大，  
把「点击 X」调小（比如 30，贴屏幕最左边），那里是纯画面区。

**Q：能翻页，但一次翻两条 / 翻不动？**  
A：拖「⚡ 滑动灵敏度」滑块。调大＝滑得更长更快，调小＝更短更慢。

**Q：能不能不用数据线升级固件？**  
A：能。手机连上设备热点后访问 `192.168.4.1/update`，把新的 `firmware.bin` 上传即可。

## 从源码编译

需要 Arduino IDE 2.x 或 arduino-cli，核心版本 **3.3.10-cn** 及以上。

**Arduino IDE 设置**

| 选项               | 值                                  |
| :--------------- | :--------------------------------- |
| 开发板              | `ESP32C3 Dev Module`               |
| USB CDC On Boot  | `Enabled`                          |
| Partition Scheme | `No FS 4MB (2MB APP x2)` ← 必须含 OTA |
| Upload Speed     | `921600`                           |

**arduino-cli**

```bash
arduino-cli compile \
  --fqbn "esp32:esp32:esp32c3:CDCOnBoot=cdc,PartitionScheme=no_fs" \
  --output-dir build esp32c3-video-remote
```

源码只有一个 `.ino` 文件，**只依赖核心自带的 BLE 库，不需要装任何第三方库**。
